========================================================================
ЛАБОРАТОРНАЯ РАБОТА: ПРОЕКТИРОВАНИЕ И ВИЗУАЛИЗАЦИЯ ГРАФОВОЙ БАЗЫ ДАННЫХ
========================================================================

НАИМЕНОВАНИЕ ПРЕДМЕТНОЙ ОБЛАСТИ: 
Информационная система управления библиотекой (Library Graph System).

ЦЕЛЬ РАБОТЫ:
Изучение принципов построения графовых баз данных в среде MS SQL Server, разработка структуры сетевых связей, написание запросов сопоставления шаблонов (MATCH) и рекурсивного обхода, а также интерактивная визуализация полученного графа отношений.

------------------------------------------------------------------------
ТЕХНИЧЕСКОЕ ЗАДАНИЕ И ШАГИ ВЫПОЛНЕНИЯ:

1. ПРОЕКТИРОВАНИЕ БАЗЫ ДАННЫХ (MS SQL Server Graph Database)
   - Создать базу данных LibraryGraphDB.
   - Развернуть три таблицы-узла (AS NODE) для хранения ключевых сущностей:
     * Readers (Читатели) — атрибуты: ID, ФИО, Номер билета, Возраст.
     * Books (Книги) — атрибуты: ID, Название, ISBN, Год издания.
     * Authors (Авторы) — атрибуты: ID, Имя автора, Страна.
   
   - Развернуть три таблицы-ребра (AS EDGE) для реализации связей:
     * Wrote (Написал) — связь между Автором и Книгой.
     * Borrowed (Взял почитать) — связь между Читателем и Книгой (с атрибутами даты выдачи и рейтинга).
     * Recommends (Рекомендует) — направленная циклическая связь (петля) от Читателя к Читателю.

2. НАПОЛНЕНИЕ ДАННЫМИ (INSERT INTO ... AS NODE / EDGE)
   - Внести тестовые записи для авторов (включая Джорджа Оруэлла, Льва Толстого и др.).
   - Добавить книги («1984», «Война и мир» и др.).
   - Добавить читателей (Иван Иванов, Пётр Петров, Анна Сидорова и др.).
   - Связать узлы ребрами, смоделировав ситуации:
     * Несколько читателей берут одну и ту же книгу.
     * Один читатель берет разные книги.
     * Построить направленную цепочку дружеских рекомендаций книг между читателями (Иван -> Пётр -> Анна -> ...).

3. РАЗРАБОТКА СКРИПТОВ И ОБХОД ГРАФА
   - Написать выборки с использованием оператора MATCH для анализа связей.
   - Реализовать алгоритм поиска кратчайшего пути по цепочке рекомендаций (алгоритм обхода графа в глубину/ширину или рекурсивное табличное выражение CTE) для поиска связи между удаленными узлами (например, от Ивана Иванова до Елены Кузнецовой).

4. СХЕМЫ В DIAGRAMS.NET (DRAW.IO)
   - Создать один файл с двумя страницами:
     * Страница 1 (DDL): Схема структуры таблиц-узлов и связей.
     * Страница 2 (INSERT): Граф конкретных данных, отражающий реальные связи между объектами из базы.

5. АНАЛИТИКА И ВИЗУАЛИЗАЦИЯ (Power BI)
   - Подключить Power BI к развернутой базе данных MS SQL Server.
   - Написать интегрированный SQL-запрос для выгрузки ребер графа в формате плоской таблицы: Источник (Source) -> Тип связи (LinkType) -> Цель (Target).
   - Внедрить специализированный визуальный элемент (граф связей Network/Force-Directed Graph).
   - Настроить интерактивную карту отношений предметной области на одной странице отчета.
